# Noor Quran Pro — نور القرآن الكريم

مشروع Flutter عربي RTL قابل للتطوير، بواجهة خضراء وذهبية.

## المزايا الموجودة في هذه النسخة
- واجهة رئيسية عربية متجاوبة مع شريط تنقل سفلي.
- جلب فهرس السور والآيات من AlQuran Cloud API عبر الإنترنت.
- البحث في أسماء السور وأرقامها.
- قارئ آيات مع مشغل تلاوة لكل آية عبر رابط صوتي خارجي.
- إضافة الآيات للمفضلة وتخزين أرقامها محليًا.
- أذكار مع عدادات لكل ذكر.
- مسبحة إلكترونية تحفظ إجمالي العدّاد محليًا.
- تقدّم ختمة مبسط (صفحات من 604) محفوظ محليًا.
- الوضع الليلي.
- معالجة أساسية لأخطاء الشبكة وزر إعادة المحاولة.

## البناء في Klencod
1. فك ضغط الأرشيف.
2. افتح مجلد `NoorQuranPro_Complete` الذي يحتوي على `pubspec.yaml`.
3. إذا كان Klencod يطلب مشروع Flutter كاملًا، استخدم خيار استيراد/فتح مجلد مشروع Flutter.
4. اضغط تصدير APK.
5. عند فشل البناء، أرسل نص الخطأ الكامل.

إذا كانت بيئة البناء تدعم Terminal:
```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```

مسار APK المعتاد:
`build/app/outputs/flutter-apk/app-release.apk`

## API
- فهرس السور: `https://api.alquran.cloud/v1/surah`
- نص سورة بالرسم العثماني: `https://api.alquran.cloud/v1/surah/{number}/quran-uthmani`
- صوت آية: `https://cdn.islamic.network/quran/audio/128/ar.alafasy/{globalAyahNumber}.mp3`

## بنية المشروع
- `lib/main.dart`: واجهات التطبيق والمنطق الأساسي.
- `pubspec.yaml`: التبعيات.
- `android/app/src/main/AndroidManifest.xml`: صلاحية الإنترنت.
- `test/widget_test.dart`: اختبار واجهة أولي.
